# Сбежавший ИИ

Проект на **ESP32-S2** с датчиком **SCD41** и дисплеем **256×160** (ST75256), 
отображающий уровень CO₂, температуру и влажность в стиле «глитч-терминала».

!(Фото)[img.jpg]

## Аппаратное обеспечение

- **ESP32-S2**
- **Sensirion SCD41** — CO₂, температура, влажность (I²C)
- **Дисплей 256×160**, контроллер ST75256 (4-wire SPI)

---

## Зависимости

- **U8g2** — драйвер дисплея
- **SensirionI2cScd4x** — работа с SCD41
- **Arduino ESP32 Core** — поддержка ESP32-S2

---

## Сборка

1. Установите Arduino IDE 2.x.
2. Добавьте поддержку ESP32 через **Boards Manager**.
3. Установите библиотеки **U8g2** и **SensirionI2cScd4x**.
4. Откройте `256x160_ESP32S2_SCD41.ino` и загрузите на плату.
